# NGMemoryDoc

Statische HTML-Dokumentation für NGMemory.

## Start

Öffne `index.html` direkt im Browser. Es ist kein Build-Schritt und kein Server notwendig.

## Inhalt

- Deutsch/Englisch-Umschaltung
- Inhaltsverzeichnis
- Suche über alle HTML-Seiten
- C#-Codeboxen mit Syntaxfarben und Copy-Button
- Module, Quick Start, Easy API, Waiting & Actions, Capture Protection, Overlays, Memory/Scanner/Debug, WinInteropTools, Screen Analysis, API-Referenz und Troubleshooting

## Dateien

- `index.html`: Startseite und Dokumentationsübersicht
- `pages/*.html`: getrennte Kapiteldateien
- `styles.css`: dunkles modernes Design
- `search-index.js`: seitenübergreifender Suchindex
- `app.js`: Sprache, Suche, aktives Inhaltsverzeichnis, Codebox-Copy und C#-Highlighting
