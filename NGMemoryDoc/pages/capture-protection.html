Privacy and recording protection

Capture Protection

NGMemory bietet direkte Display-Affinity-Helfer, einen designerfaehigen Masken-Editor, programmatische Protected Areas, unscharfe Aufnahmebereiche und schwarze Capture-Masken.

NGMemory provides direct display-affinity helpers, a designer-friendly mask editor, programmatic protected areas, blurred capture areas, and black capture masks.

Windows-RegelnWindows rules

Wichtig: SetWindowDisplayAffinity funktioniert nur für Top-Level-Fenster des eigenen Prozesses. Es schützt nicht gegen Kameras, Kernel-Capture, privilegierte Tools oder beliebige fremde Child-Controls.Important: SetWindowDisplayAffinity works only for top-level windows owned by the current process. It does not protect against cameras, kernel capture, privileged tools, or arbitrary foreign child controls.
  • WDA_MONITOR: capture shows a black window/region.
  • WDA_EXCLUDEFROMCAPTURE: supported correctly starting with Windows 10 version 2004.
  • WindowCaptureProtectionResult: contains handle, affinity, return value and Win32 error.

C#
using NGMemory.Easy;

var result = EasyWindow.SetCaptureProtection(this.Handle, true);

Console.WriteLine(result.WindowHandle);
Console.WriteLine(result.Affinity);
Console.WriteLine(result.ReturnValue);
Console.WriteLine(result.Win32Error);

ScreenshotBlurProtector

Der Blur-Protector benutzt zwei klickdurchlässige Overlay-Ebenen: eine unscharfe Ebene, die in Aufnahmen landet, und eine scharfe Ebene, die für Capture ausgeschlossen wird. So liest der Nutzer die Daten normal, während Aufnahmen verschwommen sind.

The blur protector uses two click-through overlay layers: a blurred layer that appears in capture and a sharp layer excluded from capture. Users read the data normally while recordings see blurred content.

C#
using NGMemory.CaptureProtection;

private ScreenshotBlurProtector screenshotBlur;

private void InitScreenshotPrivacy()
{
    screenshotBlur = new ScreenshotBlurProtector(this)
    {
        BlurStrength = 12,
        Padding = 3,
        LiveTracking = true,
        LiveIntervalMs = 66
    };

    screenshotBlur.ProtectControls(nameBox, mailBox, ibanBox, commentBox);
    screenshotBlur.Enable();
}

protected override void OnFormClosing(FormClosingEventArgs e)
{
    screenshotBlur?.Dispose();
    base.OnFormClosing(e);
}
  • ProtectControls: protects full control bounds.
  • ProtectRegions: protects fixed rectangles in owner-client coordinates.
  • ProtectDynamic: recomputes rectangles on every refresh, useful for scrolling lists.
  • LiveTracking: refreshes snapshots while the form is active, useful for editable fields.

CaptureBlackoutProtector

Der Blackout-Protector erzeugt Aufnahmebereiche, die schwarz werden, am Bildschirm aber praktisch unsichtbar bleiben können. Das ist robuster als echte Unschärfe, wenn nur Aufnahme-Schwärzung gebraucht wird.

The blackout protector creates areas that become black in capture while remaining practically invisible on screen. It is more robust than blur when capture blacking is enough.

C#
using System.Collections.Generic;
using System.Drawing;
using NGMemory.CaptureProtection;

private CaptureBlackoutProtector listMask;

private void InitNameColumnMask()
{
    listMask = new CaptureBlackoutProtector(this)
    {
        Padding = 1
    };

    listMask.ProtectDynamic(NameColumnRects);
    listMask.Enable();
}

private IEnumerable<Rectangle> NameColumnRects()
{
    yield return new Rectangle(120, 40, 240, 520);
}

CaptureMaskControl and ProtectedAreaManager

Designer control

C#
var maskControl = new CaptureMaskControl
{
    Dock = DockStyle.Right,
    Width = 380
};

Controls.Add(maskControl);
maskControl.BindToOwner(this);

Programmatic area

C#
var model = new CaptureMaskViewModel
{
    X = 200,
    Y = 150,
    Width = 480,
    Height = 260,
    Effect = CaptureMaskEffect.Black,
    ProtectFromCapture = true,
    OpacityPercent = 0,
    AllowInteraction = false,
    TopMost = true
};

var manager = new ProtectedAreaManager(this, model);
manager.Create();
