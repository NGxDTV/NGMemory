Release notes

NGMemory v1.0.8

Version 1.0.8 fügt ein wiederverwendbares Windows-Screen-Capture-Protection-Toolkit auf Basis von SetWindowDisplayAffinity hinzu.

Version 1.0.8 adds a reusable Windows screen-capture protection toolkit built on SetWindowDisplayAffinity.

EnthaltenIncluded

Window capture protection helpersCaptureMaskControl for WinFormsProgrammatic Protected Area APIBlack screenshot masking via WDA_MONITORScreenshotBlurProtectorCaptureBlackoutProtectorClick-through/no-activate protected areasPlaceholder and simulated blur demo modesFull docs folder

Examples

C#
using NGMemory.Easy;

var result = EasyWindow.SetCaptureProtection(this.Handle, true);

Console.WriteLine(result.Affinity);
Console.WriteLine(result.ReturnValue);
Console.WriteLine(result.Win32Error);

EasyWindow.ClearCaptureProtection(this.Handle);
C#
using NGMemory.CaptureProtection;

var model = new CaptureMaskViewModel
{
    X = 250,
    Y = 250,
    Width = 500,
    Height = 240,
    Effect = CaptureMaskEffect.Black,
    ProtectFromCapture = true,
    OpacityPercent = 0,
    AllowInteraction = false,
    TopMost = true
};

var manager = new ProtectedAreaManager(this, model);
manager.Create();

GrenzenLimits

  • SetWindowDisplayAffinity works only on top-level windows owned by the current process.
  • It does not protect normal child controls individually.
  • WDA_EXCLUDEFROMCAPTURE is correctly supported starting with Windows 10 version 2004.
  • Protection does not stop physical camera recordings, special drivers, kernel capture, or privileged capture tools.
  • Real blur of arbitrary foreign windows is not reliably possible with normal Win32/WinForms APIs.
