Quick Start

Baue NGMemory, referenziere die DLL und pruefe mit kleinen Tests, ob Fensterzugriff, Eingabe und Screenshots funktionieren.

Build NGMemory, reference the DLL, and verify window access, input, and screenshots with small tests.

EinbindenAdd to a project

NGMemory wird als Source oder direkte DLL-Referenz genutzt. Ziel ist .NET Framework 4.7.2.

NGMemory is consumed as source or direct DLL reference. The target is .NET Framework 4.7.2.

dotnet build NGMemory.sln

Fenster findenFind a window

C#
using System;
using NGMemory.Easy;

class Program
{
    static void Main()
    {
        IntPtr hwnd = EasyWindow.FindAndFocus("notepad");
        Console.WriteLine(hwnd == IntPtr.Zero
            ? "Notepad not found"
            : "HWND: 0x" + hwnd.ToInt64().ToString("X"));
    }
}

Text schreibenType text

C#
using NGMemory.Easy;

EasyWindow.FindAndFocus("notepad");
EasyKeyboard.TypeText("Hello from NGMemory", delayBetweenChars: 20);

C#
using System.Drawing.Imaging;

    bitmap.Save("screen.png", ImageFormat.Png);
