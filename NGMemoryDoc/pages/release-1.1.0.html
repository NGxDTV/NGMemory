Release notes

NGMemory v1.1.0

Version 1.1.0 ergänzt eine vollständige, abbrechbare Waiting-API für Windows-Automation sowie eine erweiterte Easy-Variante.

Version 1.1.0 adds a complete cancellable waiting API for Windows automation together with an expanded Easy layer.

NeuNew

NGMemory.Waiting

Neue Kernschicht mit Waiter, WaitOptions, WaitResult, WaitOutcome und WindowQuery.

New core layer with Waiter, WaitOptions, WaitResult, WaitOutcome, and WindowQuery.

Window automation

Warten auf Top-Level-Fenster, Kindfenster, Controls, Sichtbarkeit, Aktivierung, Vordergrund und Schließen.

Wait for top-level windows, child windows, controls, visibility, enabled state, foreground state, and closing.

Actions

Aktion einmal ausführen und auf Wirkung warten oder eine wiederholbare Aktion kontrolliert erneut versuchen.

Execute an action once and wait for its effect, or retry a repeatable action under explicit limits.

Async & cancellation

Asynchrone Gegenstücke und CancellationToken-Unterstützung für Polling, Prozesse, Signale und Aktionen.

Asynchronous counterparts and CancellationToken support for polling, processes, signals, and actions.

KompatibilitätCompatibility

Die bisherigen Methoden EasyWait.Until, ForDuration und RetryUntilSuccess bleiben quellkompatibel. Bestehender Code muss nicht umgebaut werden.The existing EasyWait.Until, ForDuration, and RetryUntilSuccess methods remain source-compatible. Existing code does not need to be rewritten.

Zielplattform bleibt .NET Framework 4.7.2 für klassische Windows-Desktop-Anwendungen.

The target remains .NET Framework 4.7.2 for classic Windows desktop applications.

Erster EinsatzFirst use

C#
using NGMemory.Easy;

IntPtr window = EasyWait.ForWindow("notepad", timeout: 10000);
if (window != IntPtr.Zero)
    EasyWindow.FocusWindow(window);
